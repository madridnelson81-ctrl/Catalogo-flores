# 🌹 Eternals Roses

**Catálogo de flores frescas** — Comayagua, Honduras

Sitio web estático del catálogo de **Eternals Roses**, una floristería que ofrece arreglos florales, bouquets y decoración para ocasiones especiales y eventos.

## ✨ Características

- Diseño moderno y responsive (móvil, tablet y escritorio)
- Secciones:
  - Arreglos destacados
  - Ocasiones especiales (San Valentín, Cumpleaños, Aniversario, Condolencias)
  - Decoración para eventos (Bodas, Fiestas, Corporativos)
  - Beneficios y contacto
- Navegación sticky
- Estilos CSS embebidos (sin dependencias externas)

## 🚀 Cómo ver el catálogo

### Opción 1: GitHub Pages (recomendado)
1. Ve a **Settings → Pages** en este repositorio
2. En **Source** selecciona la rama `main` y carpeta `/ (root)`
3. Guarda. En unos minutos el sitio estará disponible en:
   ```
   https://madridnelson81-ctrl.github.io/Catalogo-flores/
   ```

### Opción 2: Localmente
Abre el archivo `index.html` directamente en tu navegador, o usa un servidor local:

```bash
# Con Python
python -m http.server 8000

# Luego visita http://localhost:8000
```
